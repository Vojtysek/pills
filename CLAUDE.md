## Project notes

- `assets/db/sukl.db` and `src/db/reference-version.ts` are generated by `npm run build-db` — don't edit by hand.
- `src/lib/text.ts` is imported by the Node build script too, so it must stay free of imports.
- UI text is Czech; code and comments are English.
- The SÚKL test API (`testprehledy.sukl.cz`) serves outdated documents; use `prehledy.sukl.cz/dlp/v1`.
- The app must run in Expo Go for now: only use native modules Expo Go ships with. Photo/OCR (`src/lib/ocr.ts`, `matchPhoto`) is deliberately not wired into the UI until the project moves to a development build.
